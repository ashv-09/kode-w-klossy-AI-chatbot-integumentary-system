## Kode with Klossy Final Project - AI Chatbot on Integumentary Systems & Related Issues

LLM used in this AI Model is Gradio, from the Hugging Face platform which is where this was originally coded. The main file contains all the python code and interface that runs the front and user-end of the application. The attached text files are knowledge bases that the LLM uses to base responses off of.
